# シナリオテキストメーカー

台本や描写の文章を貼ると、ココフォリアの「シナリオテキスト」をまとめて作るツール。できた ZIP をルームデータとして読み込むと、シナリオテキスト一覧に並ぶ。台詞には話し手の立ち絵（表情の差分も）、描写やハンドアウトには 1 件ずつ好きな画像を付けられ、シナリオテキスト一覧から送るとメッセージボックスに画像が出る。

**公開サイト: https://shiki365.github.io/scenario-text-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要。ZIP を作る JSZip だけ cdnjs から読むので、ネットにはつながっている必要がある）。

マシュマロでいただいた「GM が 1 人でシナリオテキストから送っても、各キャラの立ち絵を出したい」という要望から作った。メッセージボックスを OBS に映すなら、姉妹ツールの [メッセージボックスメーカー](https://shiki365.github.io/message-box-maker/) を使う。ほしいツールの要望や感想は [マシュマロ](https://marshmallow-qa.com/jisg2c3imbza76d) へ。

## できること

- **作り方 2 種**
  - **台本** — 台詞を 1 件ずつ。`アリス「こんにちは」`、登録した名前なら `アリス：こんにちは` も。1 行ずつ（「」が閉じるまでは次の行も続ける）か、空行で区切ったまとまりごと。地の文は入れる / 入れない。名前に 。、！？… が入っていたら地の文扱い
  - **見出しで区切る** — `■図書館` `【図書館】` `## 図書館` などの見出しごとに、タイトル＝見出し、本文＝その下。探索箇所の描写やハンドアウトに
- **話し手** — 名前（＝送ったときの名前）、台本での別の書き方、立ち絵、表情の差分（`アリス（笑顔）「…」` `アリス@笑顔「…」`）。登録していない話し手・差分はボタンで追加できる。差分の名前をタイトルにも付ける（`アリス（笑顔）`）かどうかを選べる
- **画像の置き場** — ドラッグ＆ドロップ（何枚でも）・ファイル選択・URL で入れておき、話し手・差分・1 件ずつの画像にプルダウンで選ぶ。同じ中身の画像は 1 枚にまとめる。削除するときは使っている所を知らせる
  - **名前で自動に付く** — 見出し（`■鍵`）や話し手の名前が、置き場の画像の名前と同じなら、その画像が付く。画像を 1 件ずつ選ばなくてよい
  - **画像ごとに 1 件作る** — 置き場の画像 1 枚につき、タイトルが画像の名前のシナリオテキストを 1 件、一覧の最後に足す（本文は空。入れてから書き出す）
  - **置き場から差分を作る** — `アリス_笑顔` `アリス（笑顔）` `アリス@笑顔` のような名前の画像を、話し手 アリス の差分にする（`アリス` だけの名前の画像は、立ち絵が無いときの立ち絵にする）
  - **演出差分** — 話し手の立ち絵（ファイルの画像）から、シルエット・セピア・モノクロ・ぼかし・半透明の差分を canvas で作って置き場に入れる。背景が透明でない画像のシルエットは作らない。動く画像は最初のコマだけ。立ち絵を加工するので、描いた人が加工を認めている立ち絵だけに使う
- **手直し** — 一覧で 1 件選んで、タイトル・話し手・差分・画像（自動 / 画像なし / 置き場の画像）・本文を直す、並べ替え、足す、消す。見本はココフォリア標準のメッセージボックス風
- **確定して、次の文章へ** — 今の一覧を取っておいて、文章の欄を空にする。何回分でも 1 つの ZIP に書き出せる。戻して直すこともできる
- 本文が空のシナリオテキストは書き出さない（ココフォリアでは送信欄の文が代わりに送られてしまうため）
- 自動保存（文章と設定は localStorage、画像は IndexedDB）、プロジェクトファイル（画像も入る）

## 仕組み

ココフォリアのシナリオテキスト（`notes`）には画像の欄 `iconUrl` がある（画面から設定する所は無い）。シナリオテキスト一覧の「送信」は、**名前＝タイトル、画像＝`iconUrl`** で発言するので、`iconUrl` があればメッセージボックスに立ち絵が出る。`iconUrl` はルームデータの読み込みで入れられる。

ZIP の形は、ココフォリアの配布している JavaScript から読み取った（1.37.4、2026-09-26）。

```
__data.json   {"meta":{"version":"1.1.0"},
               "entities":{"notes":{"<20 文字の ID>":{"name":"タイトル","text":"本文","iconUrl":"<URL か画像ファイル名>","order":<数>}},
                           "room":{},"items":{},"decks":{},"characters":{},"effects":{},"scenes":{},"savedatas":{},"snapshots":{}},
               "resources":{"<画像ファイル名>":{"type":"image/png"}}}
<画像>        ZIP の直下。名前は <中身の SHA-256（16 進・小文字）>.<拡張子>（png / jpeg / gif / webp）
.token        署名。わざと合わせない
```

- **画像** — 名前が中身と合わないと無視される。読み込むとココフォリアの共有の置き場に上がり、`iconUrl` がその URL に置き換わる。`iconUrl` にはココフォリアにある画像の URL をそのまま入れてもよい
- **追加だけ** — 読み込みは ID ごとの上書きなので、新しい ID のシナリオテキストが足されるだけ。ほかの種類は空なので何も変わらない（`room` が `{}` なら更新日時だけ）
- **並び順** — `order` は「今の秒数＋連番」。あとから読み込んだものが一覧の後ろに並ぶ
- **`.token`** — 本来は `"0." + SHA-256(__data.json)`。合わせないと、ココフォリアが「外部ツールで作成および編集されたデータです…」と確認を出す。外部ツールのデータだと利用者が分かるように、わざとこの確認を出している
- 読み込めるのは GM（ルームマスター・サブルームマスター）。無料で使える（書き出しは Pro 限定だが、このツールは書き出しを使わない）

## 気をつけること

- 本物のルームで確認済み: URL の画像（2026-09-26）、ZIP に入れた画像（2026-09-28）
- ココフォリアのルームデータの形が変わると、読み込めなくなることがある
- ココフォリアの画像の上限は 5 MB。超える画像は、置き場と書き出しのときに知らせる
- 置き場の画像はブラウザの中にだけある（サイトデータを消すと消える）。別の PC に移すときはプロジェクトファイルを使う
- 購入したシナリオ（CCFOLIA GAMES など）のルームデータは改変が禁止されている。自分で作ったルームで使ってもらう
